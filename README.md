# YojanaFinder

One simple page that helps you find central government schemes you may actually qualify for.

**Live site:** https://yojanafinder.netlify.app/

## What it does

- A short 4-question finder that narrows down the schemes that fit you.
- Or browse all 22 schemes without answering anything.
- Every scheme links to its official portal — PM-KISAN, Ayushman Bharat (PM-JAY), PM Awas Yojana, Sukanya Samriddhi, PM Mudra, Stand-Up India, Atal Pension, Jan Dhan, Fasal Bima, Ujjwala and more.
- Full English and Hindi interface — one tap switches the whole page.

## How it is built

A single static HTML file with everything inline — no backend, no build step, no tracking. The scheme list and the eligibility logic live in the page itself, so it loads fast even on a slow connection.

Built for the Build Your Own Website challenge.
